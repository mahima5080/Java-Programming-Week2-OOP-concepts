# Java Programming — Week 2: Object-Oriented Programming (OOP)

## 📌 Topics Covered
* Classes and Objects
* Constructors and Overloading
* Inheritance and Polymorphism
* Abstraction and Interfaces
* Encapsulation and Access Modifiers

---

## 📁 Repository Contents
1. `Student.java`: Implementation of encapsulated student class with constructor overloading.
2. `VehicleTest.java`: Demonstrates inheritance and method overriding using `Vehicle`, `Car`, and `Bike` classes.
3. `LibraryManagementSystem.java`: **Mini Project** — A console application applying core OOP principles (Abstraction, Encapsulation, Inheritance) to manage library operations.

---

## 🚀 How to Run
```bash
javac Student.java
java Student

javac VehicleTest.java
java VehicleTest

javac LibraryManagementSystem.java
